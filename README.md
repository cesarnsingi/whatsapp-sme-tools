## Core Features (MVP Scope)

### 1. Inventory Management

Business owners can:

- Add products
- Update stock
- Check stock levels
- Receive low-stock alerts

All via WhatsApp commands.

### 2. Invoice Generation

- Create invoices
- Auto-calculate totals
- Assign invoice numbers
- Mark invoices as paid
- Track pending invoices

### 3. Payment Tracking

- Record payments
- View outstanding balances
- See monthly revenue summary

### 4. Simple CRM

- Auto-save customer phone numbers
- Track purchase history
- Track total spending
- Identify returning customers

### 5. Admin Dashboard

Web dashboard for:

- Revenue overview
- Products list
- Customers
- Invoice management
- Basic analytics

> WhatsApp remains the main interface.
